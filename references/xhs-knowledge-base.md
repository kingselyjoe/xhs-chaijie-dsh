# 小红书拆解判断基线

正式分析时读取。官方现行规则优先于运营书籍和经验；规则会变化，涉及商业合作、高风险品类或当前政策时应重新核对官方页面与更新时间。

## 官方规范审计

以小红书社区规范和商业合作规范为基础，从真诚分享、友好互动、有序经营三层判断。

| 原则 | 账号检查 | 策略判断 |
|---|---|---|
| 原创、真实、可核实 | 经验、案例、数据、身份与效果是否有证据 | 真实过程、细节和局限性是信任资产 |
| AI 辅助透明 | 是否按现行要求说明 AI 参与 | 未见标注只写合规检查项，不直接断言违规 |
| 文题相符 | 标题和封面承诺是否在内容兑现 | 包装可学，承诺大于证据必须列风险 |
| 不塑造虚假人设 | 财富、学历、收入、经历与场景能否支持 | 人设可编辑表达，不能建立在虚构资历上 |
| 资质与安全 | 医疗、健康、投资、法律等内容是否有资质和依据 | 无证据的保证性结论不列为可复制打法 |
| 友好互动 | 是否用地域、性别、职业、阶层对立或无证指控制造讨论 | 区分有信息价值的争议与恶意引战 |
| 亮明经营身份 | 品牌、店主、买手、经销或利益关系是否透明 | 伪装素人不归入可复制策略 |
| 不虚构功效和数据 | 功效、销量、评价、收益与互动是否有支撑 | 绝对化承诺、伪造数据和刷量列为风险 |
| 有序经营 | 转化路径是否符合当前平台规则 | 不把规避平台的导流话术当作运营技巧 |
| 知识产权与隐私 | 图片、音乐、肖像、案例和个人信息是否获授权 | 搬运、泄露隐私与侵权素材不可复制 |

## 账号增长判断

账号能稳定成立通常需要四个相互支持的部分：

1. 明确人群与高频需求，让用户知道“这是给谁的”。
2. 可持续生产场景，让创作者能长期稳定表达。
3. 可重复内容结构，让已验证的需求可以低成本迭代。
4. 每篇新增信息，避免机械复制消耗信任和新鲜度。

账号定位不是简介里的一个大类词，而是“谁，在什么场景，为何持续看这个账号”。分析时以主页、置顶、近期系列和评论共同验证。

## 选题与内容价值

把公开内容按主要价值归类：

- 决策价值：对比、避坑、参数、选择理由和适用边界。
- 执行价值：步骤、清单、模板、工具、流程和结果物。
- 体验价值：真实使用过程、生活场景、情绪和人格表达。
- 认知价值：解释机制、拆除误区、建立判断框架。
- 连续价值：栏目、挑战、实验、更新或长期记录。

“可收藏结构”只是可见内容特征，不能直接推断收藏原因或平台分发。

## 标题判断

检查标题是否明确包含目标人群、具体问题、使用场景、结果承诺、证据或限制条件。高热标题可以提炼为句式，但不能逐字搬运。重点比较同一需求下不同标题变体，而不是只列高赞词汇。

## 主页承接

检查头像、昵称、简介、置顶与近期内容是否支持同一承诺。主页承接的判断只说明信息是否一致、用户是否容易理解，不推断真实访问或关注转化。

## 商业化与转化

仅根据公开身份、内容承接、平台内店铺/服务入口、合作标识和用户明确提供的信息分析。不得根据内容热度推断成交、客单价或合作收入。高风险品类必须给出资质、证据、效果承诺和隐私风险。
