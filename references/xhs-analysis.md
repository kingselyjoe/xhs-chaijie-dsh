# 小红书账号分析框架

正式分析时读取。结论必须来自真实页面、真实封面和公开数据，不能把运营经验写成平台官方算法。

## 一、封面视觉审计

先打开封面原图或完整截图。缩略图过小、裁切或加载失败时不做视觉结论。

逐张记录：

1. 封面文字：主标题原文、行数、层级、关键词、数字与结果承诺。
2. 视觉主体：人物、产品、界面、前后对比、成果物或场景。
3. 构图动线：标题、主体与补充信息的阅读顺序。
4. 颜色与对比：主色、强调色、背景、文字在手机缩略图下的可读性。
5. 点击钩子：身份、痛点、反差、数字、时效、稀缺、结果或好奇心。
6. 可信证据：真实界面、过程、成品、数据、案例或身份，区分证据与装饰。
7. 系列识别：字体、人物位置、边框、标签和品牌元素的一致性。
8. 迁移判断：哪些可复用，哪些依赖体量、颜值、资源或既有人设。

输出表包含：完整封面、原笔记链接、可见互动、主标题、视觉结构、点击钩子、可信证据、可复制点、主要问题。不要只写“醒目、清晰”。

归纳最高频结构、标题句式、高热与低效视觉差异，并给出一套明确公式，例如“结果数字 + 成果截图 + 适用人群”。

## 二、账号演化分期

仅在日期和样本足够时分析。理想范围为至少 20 篇、横跨 3 个月；不足时缩小范围或改成“可见节点”。不要平均切三份，而要按真实变化点划分。

每阶段比较：定位与受众、高频主题与形态、标题与封面、可见发布日期与间隔、公开互动相对变化、代表笔记和链接。

每阶段固定回答：起止时间、代表内容与日期、当时做法、变化原因、保留什么、放弃什么。不能推断团队扩张、投流、平台扶持、收入或内部策略。

## 三、五项内容诊断

每项最多写现状、证据、判断、动作四行：

1. 定位与人群：人群、场景和长期关注理由是否清楚。
2. 选题与需求：高频选题解决购买决策、情绪共鸣、教程还是陪伴；何种需求已被多篇验证。
3. 标题与封面：高热与低效差异，是否存在可反复使用的结构。
4. 内容价值：是否提供步骤、参数、对比、选择理由或结果物。
5. 主页承接：昵称、简介、置顶和近期内容是否承接同一承诺。

## 四、可见内容机制

只分析可见设计与公开信号：

- 封面标题是否在缩略图里说清给谁、解决什么、得到什么。
- 首屏、正文或完整视频是否兑现承诺并易于扫读。
- 是否有清单、模板、步骤、参数、工具或完整案例等可收藏结构。
- 实际评论中的提问、经历、分歧、求资源或行动反馈。
- 标题、正文、话题和定位中的具体关键词承接。
- 头像、名称、简介、置顶和可见系列的一致性。
- 栏目、实验、专业身份、资源或人格表达提供的持续关注理由。

不得推断点击率、搜索排名、流量、主页访问或关注转化。

内容形态分别看：图文教程的步骤与截图证明；完整视频的开头、节奏、演示与字幕；测评种草的场景、对比标准和决策信息；直播切片的冲突点、利益点、上下文和直播承接。只看到封面时不分析视频内容。

## 五、爆款资产复用

先回溯相似标题、封面或选题是否来自历史高热样本。按“同一人群 + 同一需求 + 同一结果承诺 + 同一表达结构”分组，每组尽量取 3 篇以上。

区分：

- 有效复用：需求和结构不变，更换场景、商品、季节、案例或证据，多篇仍相对高热。
- 结构迭代：保持识别度，调整关键词、主体位置、标题长度或证据。
- 机械复制：标题、封面与内容几乎不变且公开互动持续走低。

复用表必须含资产名、首个高热样本及日期、后续笔记链接、重复元素、变化元素、公开互动范围、判定和可复制规则。

核心表达为：爆款可以重复，重复后数据会波动。账号复用的是已验证的需求和识别度，不是保证每篇爆。不能声称平台会奖励重复内容。

## 六、对标学习与发展

先给迁移公式：

`固定人群与需求 × 可持续拍摄场景 × 可重复内容结构 × 每篇新信息`

三阶段路线：

1. 起号基建：明确核心人群、高频场景、可持续表达、2-3 个内容支柱和主页承诺。
2. 验证与固化：连续测试同一结构，每次只改一个变量；同一结构 2-3 次高于自身常态或反复出现同类评论需求时固化。
3. 放大与扩展：保留核心人群与爆款资产，通过合集、对比、教程或相邻场景增加信息价值；核心内容稳定后再扩品类或人群。

每阶段写目标、必做任务、保持不变、进阶信号。最后明确向博主学什么、不学什么。

## 七、证据等级

- 可见事实：页面、图片或公开数字直接证明。
- 合理推断：多个样本与行为逻辑支持，但不是官方结论。

除非用户提供后台数据，否则不出现曝光、点击率、阅读时长、完播率、流量来源、搜索流量、主页访问、单篇涨粉、成交和转化率。不能以点赞高推断高转化，不能在没有分母时计算收藏率，不能用单篇概括整个账号。
